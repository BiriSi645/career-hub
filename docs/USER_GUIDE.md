# User Guide

## Job seeker

Register as **Job seeker**. Open **My profile & CV** to edit your profile and add education, experience, or skills. In **CVs**, use **Upload CV** to upload a PDF, DOC, or DOCX file. Use **Find jobs** to search postings and open an eligible job to apply, with an optional CV and cover letter. **Saved jobs** lists bookmarked postings. In **Dashboard**, select a posting under **Recent applications** to see its application status, history, and scheduled interviews.

**My applications** lists all your applications. Open **Notifications** to view updates and use **Mark as read** to clear an unread alert. The dashboard reflects your unread total. The seeded **Demo CV** is available as a built-in sample text download.

## Recruiter

Use **View company** on your dashboard to see a company profile. Company members can view it, and members with company management permission can edit it.

Register as **Recruiter** and open **Dashboard**. Use **Add company**, then **Post a job**. **View applicants** opens the list for a posting. Select a candidate to review their profile, download an attached CV, update the application status, or schedule an interview. When the application reaches **Offered**, use **Hire candidate** and enter the employment start date. Company membership controls which postings and applicants you can manage.

When posting a job, expand **Job skills**, select skills, and choose the minimum level and whether each is required. Use **Save draft** to keep the posting private. Postings from unverified companies start as drafts. An administrator can verify the company and open its posting. **Close** preserves the job and its applicant records. Postings without applications can be permanently deleted from a confirmation page.

Enter interview times in Istanbul time. Video interviews require a meeting URL. Use **Save status** beside an interview to mark it completed or cancelled. Applicants see the updated status and receive a notification.

## Administrator

Sign in with the administrator demo account listed in the [README](../README.md). From the dashboard you can view platform totals, manage user status and roles, verify companies, moderate postings, edit category descriptions and skill categories, and inspect employment records. The database browser displays approved tables, column information, and up to 100 rows from a selected table. It excludes password hashes and selected private fields.

Public visitors can browse and search the job board. The site uses on-screen messages for successful actions and validation errors.
